Informativa sulla Privacy e Architettura Dati

Ultimo aggiornamento: 6 Novembre 2026

Controllo Esclusivo dell'Utente: Vault è un'applicazione Local-First[cite: 1]. Non esiste un backend centrale, non esistono server aziendali e non raccogliamo alcun tipo di dato. Tutta l'applicazione, i dati inseriti, i file di configurazione e le copie di backup rimangono nel controllo esclusivo e totale dell'utente finale.

Zero Server

Nessun dato o backup abbandona mai il tuo dispositivo. Non ci sono API o database remoti[cite: 1].

Zero Tracciamento

Nessuna analisi del comportamento, nessun cookie di profilazione, nessuna telemetria[cite: 1].

Backup Sovrani

Le copie di sicurezza sono file fisici salvati esclusivamente dove decidi tu, senza intermediari[cite: 1].

1. Assenza di Titolare e Trattamento Remoto

Poiché l'applicazione opera interamente sul tuo dispositivo, non esiste alcun trattamento di dati personali da parte nostra. Non raccogliamo, non vediamo e non tratteniamo alcuna informazione. L'utente possiede il controllo assoluto sull'intera applicazione e sui suoi flussi di dati[cite: 1].

2. Controllo Totale dell'Applicazione e dei Dati

L'intera architettura di Vault è progettata per garantire che l'utente non debba delegare la fiducia a terze parti:

  • Esecuzione Locale: L'applicazione gira interamente all'interno del tuo browser o dispositivo tramite tecnologie locali[cite: 1].
  • Cifratura Autonoma: Ogni password o credenziale viene elaborata e protetta direttamente sul tuo hardware.
  • Nessun Account Remoto: Non ti viene richiesto un profilo su server esterni; l'accesso e la gestione dipendono unicamente dalle tue credenziali locali.

3. Gestione Esclusiva dei Backup

Anche le copie di sicurezza sottostanno al principio del controllo esclusivo dell'utente[cite: 1]:

  • Nessun Backup sui nostri server: Noi non disponiamo di server di archiviazione, pertanto non possiamo in alcun modo trattenere, generare o visualizzare i tuoi backup[cite: 1].
  • Autonomia di Esportazione: Qualsiasi file di backup viene esportato direttamente sul tuo dispositivo o salvato esclusivamente sui canali personali da te scelti (es. storage locale o cloud personali gestiti da te).
  • Responsabilità e Sovranità: Poiché l'intero ecosistema (app e backup) è nelle tue mani, la conservazione e la sicurezza dei file di ripristino dipendono interamente dalle tue scelte[cite: 1].

4. Diritti dell'Utente

Non essendoci alcun intermediario o server che tratti i tuoi dati, eserciti il pieno controllo su cancellazione, modifica e portabilità in modo diretto: eliminare l'app o i file locali significa cancellare ogni traccia in modo definitivo e immediato[cite: 1].
